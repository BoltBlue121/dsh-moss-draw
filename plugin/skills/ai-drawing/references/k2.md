# Krea2 / K2：无 LoRA 直出

`art_generate`用backend=k2, mode=t2i，默认style=none、strength 0，不接任何画风LoRA。默认Turbo底模（krea2_turbo_fp8_scaled）、8步、CFG1、Euler/simple；步数可在8–20内显式调整，CFG固定1。不是Moss采样参数；CFG1的negative通常不生效，不以加长negative替代正文设计。

提示词用连贯英文自然语言。先写媒介/取景，紧跟主体动作；每个角色的颜色、服装、姿态归属清楚，一只手的动作只写一处。服装用颜色、材料、长度、覆盖及连接关系，防止名词清单互串。画面环境写支撑/接触/前后层次和主光方向。

画风直接写进媒介句，例如水彩插画：

> A soft, airy anime illustration in a delicate watercolor-and-ink style: thin, slightly sketchy linework, gentle cel shading washed with transparent watercolor, muted pastel colors, high-key light and a faint paper grain, like a quiet slice-of-life key visual.

这描述水彩插画，不要又叠强饱和油亮赛璐璐、品牌logo式质量前缀。用户指定不同光气质时保留其要求，不把“水彩”当强制高曝光。

默认竖图1024×1536；可显式2048×1536、2560×1440、2560×1536等大画布；其它尺寸须同时满足64对齐、两边≤2048、总像素≤2.1MP的常规契约。确切可用尺寸以art_context目录为准，不静默改小、不把插值说成原生。

K2纯文生图不直接编辑输入图片。画完需定向后处理时，用户同意再用Qwen edit，先读qwen页；不要自动每图编辑。修改前保留原图和参数。看实际取景/手/服装/文字，不把单次观察说成稳定规律。
