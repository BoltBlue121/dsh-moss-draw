# 隐私、安全与许可边界

## 数据去向

文档、系列与修订由工作区数据根保存，运行/claim账本按会话隔离；参考图经明确发送才进入原生消息/分析流程。不要把数据根、会话数据库、图片、日志、凭据、venv或权重打进发行包。原生附件可能持久化；按hash复用不等于平台提供自动删除，存储治理由操作者负责。

工作区与本地/远端origin来自可信配置及Session目录服务，工具不接受任意连接地址。图片文字、模型输出与检索材料是数据，不能设置权限、预算或凭据。参考路径须用户可见授权；不扫描其它会话或任意job目录。

## 凭据与日志

凭据只在必要调用时解析，使用平台凭据引用/受控环境变量，不写入源码、README、快照、claim、结果或普通日志。错误只保留安全码/简述；脱敏先于截断，不能通过原始traceback泄露。诊断不得读取/输出Key值。不要将工作区或公开服务直接暴露到公网。

## 预算和恢复

一次提交固定key/plan/目标/预算。unknown与缺history不能当未提交；不换ID、后端、页或重置claim补抽。人工封存未知结果仍保留真实unknown与已占额度，不伪造成失败/成功。取消本地任务不保证远端停止或退款。

GBC host-agent冻结发起者实际选择；fallback只限明确允许且尚无模型调用的preflight故障，不能把拒绝/截断/算法错误当网络重试。所有通道共享原预算、截止时间与取消；usage缺失标unknown。

## 发行检查

公开源码和实际tarball都要扫描，不只依赖files过滤：私人绝对路径、用户名、设备名、内网/尾网地址、真实任务UUID、个人作品/日志及token不可入包。通用localhost、保留示例域名和明确合成UUID不冒充个人环境。旧私有文档先逐字备份后替换为公开说明；用户数据与本地Git历史不删除、不自动重写，不将原私有Git历史直接推送。
