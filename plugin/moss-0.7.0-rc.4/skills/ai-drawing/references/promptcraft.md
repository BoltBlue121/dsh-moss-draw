# 构图手艺：先Layout，再写描述

无论简单或复杂新文生图，先设计Layout的主体框与环境，再把英文自然语言写入summary/items。不是只有多人才能用框；单杯也要有占位、光线、接触与留白。框与文字共同表达意图，模型仍可能偏离，不能承诺像素精确。

## 六项设计

1. 主体占比：根据目的选择全身/半身/静物占比，头脚留呼吸空间。把取景范围体现在bbox和caption，不只写close-up。
2. 主光：指定方向、色温和软硬，再注明阴影细节。避免互相冲突的多个“唯一主光”。
3. 色彩：一主色、一辅色和低饱和环境，写具体颜色与面积，不堆beautiful等形容词。
4. 前中后三层：前景引导或遮挡，中景主体，背景环境；只在意图需要时增加前景，不为“层次”凭空加人。
5. 细节密度：主体精细、环境简明，主次分明。文字层的内容放text，别和装饰描述混淆。
6. 镜头：景别、机位高度、焦段感与景深一致；相机/体块是构图辅助，不是实物3D重建。

## 多人和关系

每个人/物独立item。人数贴近主体写，左右关系以画面侧或角色自身侧选一种并保持一致；每只手只有一个瞬时状态。动作写接触点与可见间隙，不靠“刚/即将”代替几何。家具需要落地点和统一空间，不能要求不可见的腿全部露出。hidden与locked是文档控制，不保证生成像素身份。

## 参考图复刻

先读取可见原图；新生图按analysis做GBC→Layout提案，不把generation.prompt当完整布局。摘要缺bbox时使用结构转换，不编造看见的坐标。contain/cover/stretch与目标画布一致，裁切要说明。

用户已有可复用结果时保留原params/seed，在原文上局部替换要求改的部分；更改Layout后核对文案，重新冻结尚未执行的新计划。不能为了比较而重放unknown提交。同参数对比只能说明该样本，不推导普遍成功率。

## 审图和下一步

人数与归属→朝向/遮挡→动作/接触→取景裁切→家具支撑→光线与留白→颜色/部件逐侧→手与解剖→文字→不可变要求。实际像素事实与用户描述/假设分开，看不清写UNKNOWN。

未达标就明确差异，给最小下一步修改建议；不自动再抽一张。新的生成需要剩余明确授权，unknown先对账原run。变更多处不能证明单一因果，不能把技术成功称为视觉合格。
