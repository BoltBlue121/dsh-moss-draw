# 04 · 内容与隐私说明

本仓库是公开发布版本，发布面的范围是：`plugin\`（插件源码与运行时资产）、`install\`、`verify\`、`dist\`（打包脚本与构建产物）、`docs\`、`README.md`、`LICENSE`。凡只对作者本机、本机网络或个人素材成立的字符串与文件都不在其中。

本文用四个占位符：`<repo>` 表示仓库根目录，`<DshHome>` 表示 DSH home（默认 `%USERPROFILE%\.dsh`），`<workspaceRoot>` 表示允许插件读图的绝对目录，`<comfy-host>` 表示 ComfyUI 的主机名或地址。

## 1. 故意剔除的内容

| 类别 | 发布面里不得出现的形式 | 处理方式 | 自动扫描项 |
|---|---|---|---|
| 个人绝对路径 | 带盘符的用户目录、工作区、ComfyUI 安装路径；`/Users/<name>` 形式 | 一律改成占位符或示例路径：`<workspaceRoot>`、`<DshHome>`、`<comfy-host>`；配置只有 `__MOSS_WORKSPACE_ROOT__`、`__MOSS_COMFY_URL__`、`__MOSS_DATA_ROOT__` | `windows-user-path`、`posix-user-path` |
| 内网与隧道地址 | `10.x`、`172.16–31.x`、`192.168.x`；Tailscale 的 `100.64–127.x` | 文档只用 `http://127.0.0.1:8188` 与 `<comfy-host>` 示例 | `private-lan-ip`、`tailscale-cgnat` |
| 模型渠道/服务商名字 | 某中转站、某聚合服务的实名，及其在 persona、description、文档里的特指 | 统一写成「本机已配置的、能看图的模型渠道」；插件不内置渠道 | `personal-provider` |
| 凭据 | API Key、Bearer token、私钥、账号口令；URL 里的 userinfo | 不写入任何文件；`comfyUrl` 校验直接拒绝带 userinfo 的 URL | `credential-material`、`personal-mail-domain` |
| 私有画风 LoRA | 自训画风 LoRA 的文件名、触发词、强度实验结论 | 内置画风只有 `none`，`lora_strength` 必须 0；`STYLES`、K2 模板、模式列表里都不再有私有条目 | `private-style-lora` |
| 个人剧情与角色文案 | 具体作品里的角色名、故事设定、剧情片段（包括测试 fixture） | 测试与示例改用中性占位描述；`fixtures` 已中性化 | `personal-story-name` |
| 开发报告与维护记录 | 内部开发文档、实验流水账、本机验收现场记录、版本维护日志 | 不随包；本仓库只有面向部署方的 5 篇文档 | 人工复核 |
| 会话与生成物 | 历史会话、工作台数据、生成的图片 | 不随包；运行时全部写在 `<dataRoot>` | 人工复核 |
| 模型权重与 LoRA 权重 | 任何 `.safetensors`/`.ckpt`/`.pth` | 不随包；由部署方自备并遵守各自许可 | 人工复核 |
| 第三方提示词库原文 | 其它项目的提示词库正文、摘录或改写 | 不随包；`art_guide` 只提供本插件自己写的接口页与参数页 | 人工复核 |

补充说明：

- `plugin\client\lib\client.js` 是构建产物，早期构建里可能残留已删除的字符串。发布前必须用 `plugin\scripts\build-client.mjs` 从当前源码重建，不手改产物。
- `plugin\tests\` 里的 fixture 是测试输入，同样按上表处理；个人剧情/角色名在 fixture 中也不允许出现。
- 包的 `files` 白名单只收运行时文件；`tests\`、开发文档与 `.work\` 过程产物不进入 tarball。

## 2. 自动扫描（发布前的硬门槛）

`verify/sanitize-scan.mjs` 是发布面的自动检查。它只扫文本扩展名（`.mjs`、`.js`、`.cjs`、`.json`、`.md`、`.css`、`.py`、`.yml`、`.yaml`、`.txt`、`.ps1`、`.ts`），跳过 `.git`、`node_modules`、`.verify-work`、`verification`、`dist`、`.work`。

> 下面的 `node` 指任意 node 24。新机器上若没有 `node` 在 PATH 里，用官方 Desktop 的 Node 模式代替：先设 `$env:ELECTRON_RUN_AS_NODE = '1'`，再执行 `& "$env:LOCALAPPDATA\Programs\DeepSeek Harness\DeepSeek Harness.exe" <脚本> <参数>`。

```powershell
# 扫插件发布面；0 命中 exit 0，有命中 exit 1
node .\verify\sanitize-scan.mjs --dir .\plugin --out .\verification\sanitize-scan.json

# 扫解包后的 tarball（先解出 verification\tgz-extract\package）
node .\verify\sanitize-scan.mjs --dir .\verification\tgz-extract\package --out .\verification\sanitize-scan-tgz.json
```

参数只有 `--dir`、`--out`、`--json`。退出码：`0` 无命中；`1` 有命中；`3` 目录不存在。命中时每条形如：

```json
{"file":"src/example.mjs","line":12,"pattern":"private-lan-ip","match":"<private-lan-address>","excerpt":"const url = 'http://<private-lan-address>:8188';"}
```

`pattern` 的取值集合：

| pattern | 检测对象 |
|---|---|
| `windows-user-path` | 带盘符的 `Users`/`agent`/`ComfyUI`/`Program`/`dsh`/`DSH` 顶层路径 |
| `posix-user-path` | `/Users/<name>` |
| `tailscale-cgnat` | `RFC 6598 共享地址空间` 段地址 |
| `private-lan-ip` | `10/8`、`192.168/16`、`172.16/12` 段地址 |
| `personal-provider` | 私有渠道/服务商名字 |
| `private-style-lora` | 私有画风 LoRA 名（含触发词来源） |
| `personal-story-name` | 个人作品里的角色/剧情名 |
| `credential-material` | API Key、`sk-`、Bearer、私钥头 |
| `personal-mail-domain` | 常见个人邮箱域 |

脚本本身不含这些私有名字：检测词以 base64 编码后随脚本分发，运行时再解码。**不要为了变绿去改扫描器、加白名单或把真实值藏进注释**；命中就改源文件。

`verify/cold-load.cjs` 与 `verify/client-load.cjs` 各自带一份同样的标记黑名单：前者在假 profile 冷加载时校验加载面，后者校验客户端 bundle 里没有残留的私有画风/渠道字符串。`verify/run-verify.ps1` 会把上述扫描（包含解包树那份）纳入一键验收。

## 3. 人工复核

自动扫描只覆盖写进规则的模式，发布前再过一遍：

- [ ] `plugin\cordis.patch.yml` 只有三个占位符，没有任何真实盘符路径或 URL。
- [ ] `plugin\package.json` 的 `description`、`keywords`、`repository` 只有中性信息；版本是 `0.8.0`。
- [ ] `plugin\src\catalog.mjs` 的 `STYLES` 只有 `none`；`DEFAULTS.style` 为 `none`、`lora_strength` 为 0。
- [ ] `plugin\templates\` 里没有任何私有 LoRA 文件名（K2 模板无 `LoraLoaderModelOnly`）。
- [ ] `plugin\skills\ai-drawing\` 与 `plugin\worker\README.md` 无本机路径、内网地址、渠道实名。
- [ ] `plugin\client\lib\client.js` 与当前源码重建结果一致（`node plugin\scripts\build-client.mjs` 后可比对哈希）。
- [ ] `README.md` 与 `docs\` 里没有本机用户名、真实主机名、私有目录、真实 ComfyUI 地址。
- [ ] 没有 `.env`、日志、导出的会话、截图或生成物被误加进目录。
- [ ] 解包后的 tarball 里没有 `tests\`、`.work\`、开发文档。

## 5. 重新发布前的最小流程

```powershell
# 1) 重建客户端 bundle（改了 client/ 源码时）
node .\plugin\scripts\build-client.mjs

# 2) 重建 tarball 与校验和
node .\dist\build-package.mjs

# 3) 发布面扫描必须 0 命中
node .\verify\sanitize-scan.mjs --dir .\plugin --out .\verification\sanitize-scan.json

# 4) 全量验收
.\verify\run-verify.ps1 `
  -KitRoot . `
  -DesktopDir "$env:LOCALAPPDATA\Programs\DeepSeek Harness" `
  -DshHome "$env:USERPROFILE\.dsh"
```

四步全绿后，把 `verification\verify-summary.json`、`sanitize-scan.json`、`sanitize-scan-tgz.json` 与 `package-integrity.json` 作为本次发布的证据留档；验收细节见 [03-验证与验收.md](03-验证与验收.md)。
